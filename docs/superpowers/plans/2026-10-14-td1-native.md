## Review Focus

- Optional feature must not accidentally advertise fixture/test execution as production.
- Malformed artifact/output slots/budgets must fail without retaining or partially transferring resources.

- Releasing model/session/input must not invalidate retained state or owned results.
- Real C/C# acceptance must use trained bytes and reference predictions, never fixture output.
